Friend notifications, your watch history, and real watch time.

## Install
Download **`trackr-v1.14.0.apk`** below and open it on your phone. It installs over earlier 1.x versions and keeps your list and sign-in.

## What's new
- **Friend notifications**: get notified about friend requests, accepted requests, comments and reactions on your titles, and recommendations, even when Trackr is closed. Trackr checks about every 15 minutes. Turn it off in Settings → Notifications → Friend activity.
- **Your history**: each title page shows what you watched and when ("Episodes 5–7 · Yesterday"). Episodes marked the same day merge into one line.
- **Rewatches**: tap "Watch again" on a finished title to start over, and set how many times you've watched it.
- **Real watch time**: Profile shows the hours you've spent watching, using each title's actual runtime and counting rewatches. Year in review counts the episodes you watched that year.
- **Faster sync**: list changes go up in one request instead of one per title, so big imports sync in seconds.
- **Background sync fix**: syncing in the background no longer skips when Trackr was closed.
