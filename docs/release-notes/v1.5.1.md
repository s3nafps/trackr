Notifications are now set up when you start Trackr.

## Install
Download **`trackr-v1.5.1.apk`** below and open it on your phone. It installs over earlier 1.x versions and keeps your list and sign-in.

## What's new
- **Notification prompt on first launch**: Trackr asks once for permission to send notifications, so new-episode alerts work without a trip to Settings.
- **Alerts right on time**: it then offers to open "Alarms & reminders" so episode alerts arrive the moment an episode airs. Allowing it later also updates alerts that are already scheduled.
- If you'd already allowed both, nothing is asked.
