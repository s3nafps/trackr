Update notifications, and a fix for choosing a username.

## Install
Download **`trackr-v1.13.0.apk`** below and open it on your phone. It installs over earlier 1.x versions and keeps your list and sign-in.

## What's new
- **Update notifications**: when a new version is out, Trackr sends a notification. Tapping it opens the update window.
- **See every change**: the update window lists what's new in each version since yours, not just the latest.
- **Usernames save again**: the username box now only takes what a username can hold (English letters, numbers, . and _), so names typed with other letters no longer fail to save.
