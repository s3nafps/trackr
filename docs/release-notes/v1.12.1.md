A small release with fixes from a security review. Nothing you'd notice day to day changes.

## Install
Download **`trackr-v1.12.1.apk`** below and open it on your phone. It installs over earlier 1.x versions and keeps your list and sign-in.

## What's new
- **Friends by invite code**: adding a friend with an invite code uses a dedicated lookup. Your invite code shows only on your own profile.
- **Safer in-app updates**: Trackr installs an update only after the download matches the checksum GitHub publishes for that release.
- **Taps from notifications and widgets** open only titles Trackr can show, the same as shared links.
